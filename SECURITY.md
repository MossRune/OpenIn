---

## Reporting a Vulnerability

The OpenIn maintainers take security and user privacy seriously. If you discover a security vulnerability or sensitive defect, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Send an email to the project maintainers with details, reproduction steps, and impact assessment.
3. You can also utilize [GitHub Private Vulnerability Reporting](https://github.com/MossRune/OpenIn/security/advisories/new) on the OpenIn repository.

### What to Include in Your Report
- Detailed description of the vulnerability.
- Steps to reproduce or proof of concept.
- Target platform (Windows, macOS, Linux).
- Any potential impact on user systems or URL handling.

### Response Timeline
- We will acknowledge receipt of your report within 48 hours.
- We will coordinate a fix and release a patched version promptly.
- We will credit reporters in our release notes (unless anonymity is requested).
